Antes de empezar

Objetivo: tener Python funcionando y saber dónde escribir tu primer código.

Datos faltantes: NaN y None

En datos reales siempre falta algo. NumPy y pandas marcan los faltantes como NaN (Not a Number); en una lista común puedes ver None.

import numpy as np
import pandas as pd

edades = np.array([20, np.nan, 22, 19])
print(np.mean(edades))      # nan: numpy no ignora faltantes
print(np.nanmean(edades))   # versión que los ignora

s = pd.Series([20, None, 22, 19])
print(s.mean())             # pandas los ignora por defecto
print(s.isna().sum())       # cuántos faltan

Ojo con la diferenciaLas funciones de pandas (.mean(), .std(), .sum()…) ignoran los faltantes por defecto. Las de NumPy no: devuelven nan, a menos que uses su versión np.nan... (np.nanmean, np.nanstd).

Las líneas import numpy as np e import pandas as pd cargan las librerías con un nombre corto. Lo verás al inicio de todo análisis.

Tu turno: programa la moda a mano pandas ya trae .mode(), pero programarla te enseña dos herramientas clave: los diccionarios y los bucles. Escribe moda(datos) que cuente cuántas veces aparece cada valor y devuelva los más repetidos.
Ver una pista

Un diccionario guarda pares valor: conteo. Recorre los datos con for x in datos: y suma 1 al conteo de x. conteo.get(x, 0) devuelve 0 si x todavía no está.

Ver solución
def moda(datos):
    conteo = {}                         # diccionario: valor -> veces que aparece
    for x in datos:
        conteo[x] = conteo.get(x, 0) + 1
    maximo = max(conteo.values())
    return [x for x, c in conteo.items() if c == maximo]

print(moda(notas))
print(moda([1, 1, 2, 2, 3]))   # bimodal: devuelve las dos
[7.5]
[1, 2]

def crea una función, y lo que va después de return es lo que devuelve. Fíjate en la sangría (los espacios al inicio de cada línea): en Python indica qué líneas están dentro de la función o del bucle.

Medidas de dispersión

Objetivo: medir qué tan parecidos o diferentes son los datos entre sí.

Dos cursos pueden tener la misma media y ser muy distintos: en uno todos sacaron cerca de 7; en el otro, la mitad 4 y la mitad 10. La dispersión mide esa diferencia.

print(nota.min(), nota.max())          # mínimo y máximo
print(nota.max() - nota.min())         # rango
print(nota.var())                      # varianza
print(nota.std())                      # desviación estándar
print(nota.quantile(0.75) - nota.quantile(0.25))   # rango intercuartílico
4.8 9.4
4.6000000000000005
1.93719696969697
1.3918322347527987
1.5749999999999984
Cómo leer la desviación estándarEs la distancia típica de cada dato a la media, en las mismas unidades que tus datos. Aquí, las notas se alejan unos 1.4 puntos de la media de 7.36.

La trampa de ddof: muestral o poblacional

print(np.std(notas))            # numpy: divide entre n (poblacional)
print(np.std(notas, ddof=1))    # ddof=1: divide entre n-1 (muestral)
print(nota.std(ddof=0))         # pandas también acepta ddof
1.3325779110014127
1.3918322347527987
1.3325779110014127
pandas y NumPy no coincidenpandas divide entre n − 1 (fórmula muestral, la que suelen pedir los cursos), y NumPy divide entre n (poblacional). Si tus resultados no coinciden con los del libro, revisa el ddof. Así como lo estamos usando, pandas da los mismos resultados que Excel (DESVEST) y que R.

Coeficiente de variación (CV)

Compara la dispersión de variables con unidades distintas: es la desviación estándar como porcentaje de la media.

def cv(x):
    return x.std() / x.mean() * 100

print(cv(estudiantes["nota"]))
print(cv(estudiantes["horas"]))
18.91504735790893
39.14948523083309

Las horas varían mucho más (39%) que las notas (19%). Una guía común: menos de 15% es poco disperso; más de 30%, muy disperso.

Forma: asimetría y curtosis

  • Asimetría cercana a 0: simétrica. Negativa: cola larga hacia los valores bajos. Positiva: hacia los altos.
  • Curtosis en exceso cercana a 0: como la normal. Negativa: más plana. Positiva: más puntiaguda y con colas pesadas.

Con las dos fórmulas la conclusión es la misma: una ligera cola hacia las notas bajas y una forma algo más plana que la normal. Los números difieren porque pandas aplica una corrección para muestras pequeñas. Usa siempre la misma fórmula en un mismo informe.

En pandas casi todo método devuelve una tabla nueva, así que puedes encadenarlos con un punto. Si envuelves la cadena entre paréntesis, puedes poner un paso por línea:

  
resultado = (

.query("condición")Se queda con las filas que cumplen la condición

      
[["col1", "col2"]]Elige columnas

resumen_carrera = (

Correlación entre variables

  
Objetivo: medir si dos variables numéricas se mueven juntas y con qué intensidad.

  
El coeficiente de correlación va de −1 a 1. Positivo: cuando una sube, la otra también. Negativo: cuando una sube, la otra baja. Cerca de 0: no hay relación lineal.

  
print(estudiantes["horas"].corr(estudiantes["nota"]))                     # Pearson
print(estudiantes["horas"].corr(estudiantes["nota"], method="spearman"))  # por rangos
print(estudiantes[["edad", "horas", "nota"]].corr().round(2))           # matriz
0.9315614223347137
0.9000000000000001
       edad  horas  nota
edad   1.00  -0.01 -0.15
horas -0.01   1.00  0.93
nota  -0.15   0.93  1.00

  

    
Valor absoluto de rInterpretación orientativa

    
      
0.00 – 0.29Débil o nula

      
0.30 – 0.69Moderada

      
0.70 – 1.00Fuerte

    
  

  
    
    
  • Pearson (por defecto): mide relación en línea recta. Sensible a atípicos.
    • 
    
  • Spearman: usa el orden de los datos. Mejor con atípicos, variables ordinales o relaciones curvas que siempre suben.
    • 
  

  
Para ver la matriz como mapa de calor: sns.heatmap(estudiantes[["edad", "horas", "nota"]].corr(), annot=True, cmap="coolwarm").

  
Correlación no es causalidadLas ventas de helado y los ahogamientos están correlacionadas porque ambas suben en verano. Que dos variables se muevan juntas no prueba que una cause la otra. Grafica antes de concluir.

  
Covarianza

  
print(estudiantes["horas"].cov(estudiantes["nota"]))
4.653030303030303

  
Indica la dirección, pero su tamaño depende de las unidades. Para interpretar se usa la correlación, que es la covarianza estandarizada.
