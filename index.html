Antes de empezar

Objetivo: entender qué es programar, ejecutar tu primer código y aprender a leer un error.

Programar es escribir instrucciones para que la computadora las siga, una por una y en orden. Python es uno de los lenguajes más usados para eso porque se lee casi como inglés. Con él se hacen páginas web, se automatizan tareas aburridas, se analizan datos y se crea inteligencia artificial.

AnalogíaUn programa es como una receta de cocina. La computadora es un cocinero muy rápido, pero completamente literal: hace exactamente lo que dice la receta, ni más ni menos. Si la receta tiene un error de escritura, se detiene y te avisa.

  • self es “este objeto en particular”. Por eso self.nombre es el nombre de cada perro.
  • Los atributos son los datos (nombre, edad) y los métodos son las funciones de la clase (ladrar).

class CuentaBancaria:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def depositar(self, monto):
        if monto <= 0:
            raise ValueError("El depósito debe ser positivo")
        self.saldo += monto

    def retirar(self, monto):
        if monto > self.saldo:
            raise ValueError("Saldo insuficiente")
        self.saldo -= monto

    def __str__(self):                  # cómo se ve al imprimirlo
        return f"Cuenta de {self.titular}: ${self.saldo:,.2f}"

print(cuenta)

except ValueError as error:
    print("Error:", error)

Error: Saldo insuficiente

La clase protege sus reglas: no se puede retirar más de lo que hay. __str__ define cómo se ve el objeto al imprimirlo.

class Rectangulo:

    while True:          # infinito, pero solo calcula lo que se pide
        yield a
        a, b = b, a + b

Decoradores: envolver funciones

Un decorador recibe una función y devuelve otra que le agrega algo, sin tocar el código original. Se aplica con @.

def anunciar(funcion):
    def envoltura(*args):
        print(f"Llamando a {funcion.__name__}{args}")
        resultado = funcion(*args)
        print(f"Resultado: {resultado}")
        return resultado
    return envoltura

@anunciar                  # equivale a: sumar = anunciar(sumar)
def sumar(a, b):
    return a + b

def pares(limite):

class GestorTareas:
    def __init__(self):
        self.tareas = []

    def agregar(self, titulo):
        titulo = titulo.strip()
        if not titulo:
            raise ValueError("El título no puede estar vacío")
        self.tareas.append(Tarea(titulo))

    def completar(self, numero):
        if not 1 <= numero <= len(self.tareas):
            raise ValueError(f"No existe la tarea {numero}")
        self.tareas[numero - 1].hecha = True

    def listar(self):
        if not self.tareas:
            print("No hay tareas")
        for i, tarea in enumerate(self.tareas, start=1):
            print(f"{i}. {tarea}")

    def pendientes(self):
        return sum(1 for t in self.tareas if not t.hecha)

gestor = GestorTareas()
gestor.agregar("Estudiar Python")
gestor.agregar("Hacer ejercicio")
gestor.completar(1)
gestor.listar()
print("Pendientes:", gestor.pendientes())

import json

def guardar(gestor, ruta="tareas.json"):
    datos = [{"titulo": t.titulo, "hecha": t.hecha} for t in gestor.tareas]
    with open(ruta, "w", encoding="utf-8") as f:
        json.dump(datos, f, ensure_ascii=False, indent=2)

def cargar(ruta="tareas.json"):
    gestor = GestorTareas()
    try:
        with open(ruta, encoding="utf-8") as f:
            for d in json.load(f):
                gestor.tareas.append(Tarea(d["titulo"], d["hecha"]))
    except FileNotFoundError:
        pass                      # primera vez: empezamos sin tareas
    return gestor

def menu():
    gestor = cargar()
    while True:
        print("\n1) Ver  2) Agregar  3) Completar  4) Salir")
        opcion = input("Elige una opción: ").strip()
        try:
            if opcion == "1":
                gestor.listar()
            elif opcion == "2":
                gestor.agregar(input("Título: "))
                print("Tarea agregada")
            elif opcion == "3":
                gestor.completar(int(input("Número de tarea: ")))
                print("¡Bien hecho!")
            elif opcion == "4":
                guardar(gestor)
                print(f"Guardado. Tareas pendientes: {gestor.pendientes()}")
                break
            else:
                print("Opción no válida")
        except ValueError as error:
            print("Error:", error)
